# AudioSelector

![applogo](https://github.com/karakirimu/AudioSelector/blob/main/AudioSelectorPackage/Images/SmallTile.scale-200.png?raw=true)

AudioSelector is a simple Windows tray app for switching both playback devices and microphones.

It lets you open speaker and microphone selection windows with hotkeys or from the tray icon, choose which selector opens on double-click, and adjust theme, language, and startup behavior from the settings window.

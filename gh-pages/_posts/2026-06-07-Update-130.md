Changelog 1.2.0 -> 1.3.0

- You can now select the input device with `Ctrl + Alt + N`.
- You can now change the hotkeys for input devices and output devices.
- Added a setting to change the action triggered by double-clicking the tray icon.
- Improved stability.
- Added crash report collection for the Store version only. It does not work in the portable version.
- Updated the privacy policy.
